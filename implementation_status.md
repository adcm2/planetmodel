# Implementation status

Phase A adds a native, in-memory C++ radial model built from MINEOS decks. It owns layer interpolants, preserves layer/interface names and source knots, and carries SI scales, model-unit `G`, source identity, and optional `omega_ref`. Elastic properties and radial derivatives are evaluated from primitive fields with Python-compatible description precedence. MINEOS layers carry Fluid/Solid metadata derived from shear source knots; generic layers default to Unknown and require a declared phase for layer-wide classification.

Phase B adds `RadialGravity`, which adaptively integrates radial density with embedded Gauss-Kronrod estimates, splits at source breakpoints, and caches accepted mass prefixes. Layer-indexed queries select one-sided interface values; model-radius queries include a zero-field hollow cavity. `PreparedConstantQ` caches real Love moduli and Voigt bulk/shear loss coefficients for repeated frequency evaluation, exposes the shared `ConstantQFactor`, applies the `exp(+i omega t)` lower-half-plane convention, and refuses viscosity, Prony and power-law inputs. No pressure or other rheology model is included.

The C++ README documents the API and breakpoints. Focused GTests cover model metadata, one-sided interfaces, analytic gravity, hollow cavities, adaptive integration and work-budget exhaustion, isotropic/TI conversions, Q dispersion and frequency symmetry, and invalid inputs. Fresh g++-13 builds with warnings as errors passed: 73/73 available NetCDF tests and 43/43 available no-NetCDF tests, including consumer builds; the two gmsh/PyMFEM fixture cases were unavailable. The strict Doxygen build passed. Cross-language checks passed 6,256 Phase A material comparisons (maximum scaled difference 2.90e-15), 8,993 Phase B gravity/attenuation comparisons (maximum 1.55e-15), and 28 unit-rescaling checks (maximum 7.56e-16). Independent Luna and Sol code reviews passed.
