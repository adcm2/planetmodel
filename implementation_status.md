# Implementation status

Phase A adds a native, in-memory C++ radial model built from MINEOS decks. It owns layer interpolants, preserves layer/interface names and source knots, and carries SI scales, model-unit `G`, source identity, and optional `omega_ref`. Elastic properties and radial derivatives are evaluated from primitive fields with Python-compatible description precedence. MINEOS layers carry Fluid/Solid metadata derived from shear source knots; generic layers default to Unknown and require a declared phase for layer-wide classification.

Phase B adds `RadialGravity`, which adaptively integrates radial density with embedded Gauss-Kronrod estimates, splits at source breakpoints, and caches accepted mass prefixes. Layer-indexed queries select one-sided interface values; model-radius queries include a zero-field hollow cavity. `PreparedConstantQ` caches real Love moduli and Voigt bulk/shear loss coefficients for repeated frequency evaluation, exposes the shared `ConstantQFactor`, applies the `exp(+i omega t)` lower-half-plane convention, and refuses viscosity, Prony and power-law inputs. No pressure or other rheology model is included.

The TI attenuation extension adds explicit `additive` (default) and `fixed_ratios` choices in Python and C++. Fixed ratios preserve `C/A`, `N/L` and `F/(A - 2L)` while matching the same complex Voigt bulk and shear moduli. True isotropic fluids use the bulk branch; undefined ratios, ill-conditioned mappings, non-passive loss tensors and invalid prescription values are rejected. Python exposes `ti_prescription` through `frozen_moduli`, `dispersive_moduli` and `frozen`; C++ exposes `TIPrescription` and `Prescription()`. Independent Luna high and Sol reviews passed, including verification of the invalid-enum repair.

Validation passed with GCC 13 warnings as errors: 79 available NetCDF checks (including examples), 45 without NetCDF, 200 relevant Python checks, and strict Doxygen. Two existing Gmsh/PyMFEM fixture cases remain unavailable. The extension adds two focused test groups per language. One-time checks covered 11,730 native/Python modulus values, Voigt targets and ratio constraints (maximum scaled modulus difference 1.47e-15), and 455 SI-rescaled values (6.51e-16). Sampled additive outputs matched the previous commit exactly: 5,865 Python and 7,820 native complex modulus values. Earlier A/B comparison provenance remains in the ignored `build/ab-validation-20261022` directory. DSpecM1D migration and seismogram comparisons have not been run for this extension.
